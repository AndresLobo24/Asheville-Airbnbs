# Boone Coffee Shops Mapping Project

This project is an interactive web map that visualizes the distribution and quality of coffee shops in Boone, North Carolina. The map combines zoning district data with Yelp-sourced coffee shop locations and ratings to offer insight into the spatial patterns of Boone’s local café culture. Each zoning district is shaded using a choropleth style to represent the number of coffee shops within that area, ranging from 0 to 5, with lighter to darker shades of brown to match the coffee theme. This helps users quickly identify which parts of town have higher concentrations of coffee shops.

Coffee shops are represented with icon markers styled as coffee mugs using Font Awesome. These icons are color-coded based on Yelp ratings: red lower-rated shops (2.9–3.5), yellow for average ratings (3.6–4.3), and green for the best-rated spots (4.4–5.0). While Yelp reviews can range from 0-5, the lowest rating in Boone was 2.9 and the highest was 5 so this was the range used to signify quality. Clicking on a coffee shop icon reveals its name and rating in a popup. Additional map features include a clear legend that explains the color symbology and a scale bar for spatial reference.

This project utilizes several open-source libraries, including [Leaflet.js](https://leafletjs.com/) for the interactive map interface, [Chroma.js](https://gka.github.io/chroma.js/) for color scaling, jQuery for DOM manipulation, and Font Awesome for icons. The zoning data was obtained from the Boone Planning Department, while the coffee shop data and ratings were sourced from Yelp. The project was created by Andres Lobo as a way to explore geospatial visualization, data integration, and user-friendly web mapping tools for community-focused data.
